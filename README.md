# Thực hành Bootstrap Navbar

Mở `index.html` bằng trình duyệt có kết nối Internet để tải Bootstrap 5.3.0 từ CDN theo đề bài.

## Chức năng

- Navbar tối màu với thương hiệu MyWebsite.
- Menu Home, About, Services, Contact.
- Dropdown Services có Web Design và SEO.
- Sử dụng navbar-expand-lg: menu ngang từ 992px; dưới 992px dùng nút toggler mở/đóng menu.
- Có aria-controls, aria-expanded và nhãn cho nút menu.
- Các liên kết dẫn tới những phần nội dung có thật trong trang.

## Tệp

- `index.html`: cấu trúc Navbar và nội dung minh họa.
- `style.css`: định dạng bổ sung.
- `desktop-dropdown.png`: menu dropdown trên desktop.
- `mobile-menu.png`: menu mở trên mobile.

Dropdown và collapse sử dụng bootstrap.bundle.min.js; không cần JavaScript tùy chỉnh.
